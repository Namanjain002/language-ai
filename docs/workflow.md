# Workflow

The user opens the chat and is prompted with a greeting message: **"What's Up"**.

The user types his message, which may or may not contain grammatical errors.

## If the sentence is grammatically correct

Continue with the normal chat.

## If the sentence contains grammatical errors

Use the reference box style text box and:

- Correct the user's grammar.
- Rewrite the entire sentence with proper grammar and punctuation.
- Display the correction in the light-grey section.
- Continue the conversation in the darker section.

## Inactivity Summary

If the user is inactive for a period of time (say 1–2 hours), generate a summary of the user's grammar weaknesses.

### The summary will NOT contain

- What the user talked about
- The story/conversation
- The user's mood or feelings

### The summary WILL contain

- The grammar areas where the user is weak.

For example, if the user repeatedly makes tense mistakes, the summary should contain:

> **Tenses**

rather than describing the conversation itself.
